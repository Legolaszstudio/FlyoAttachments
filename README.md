# Flyo Melléklet

Üdvözöllek a technikusi vizsgamunkánk (Informatikai Rendszer- és Alkalmazás-Üzemeltető Technikus) melléklet tárolójában!

A mellékletek struktúrája a következő:
- IMAGES (Képek, Ábrák, Diagramok, stb.)
- CONFIGURATIONS (Teljes router és eszköz beállítások.)
- TESTS (Teszteléseket bemutató dokumentumok, képek, videók, stb.)
